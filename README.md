# GR Cutter — Android

[**Baixar APK para Android**](https://github.com/pietrotm2015-hub/gr-cutter-downloads/releases/latest/download/GR_Cutter_Android.apk)

Canal público de instalação e atualização do GR Cutter para Galaxy S20 FE e Poco X3 Pro. Nenhum login é necessário para baixar.

Instale por cima da versão anterior para manter o cache e a fila. Depois da primeira instalação desta versão, as novas versões aparecem em **Offline → Atualizações do app**.

Este repositório distribui APKs assinados e informações de versão. O código do aplicativo permanece privado.
